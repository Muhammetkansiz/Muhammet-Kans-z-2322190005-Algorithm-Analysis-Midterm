## 📌 Project Overview
This repository contains the implementation, runtime tracing, and comprehensive theoretical/practical analysis of two distinct sorting algorithms: **Bubble Sort** and **TimSort**[cite: 5, 6].

The analysis evaluates each algorithm based on:
1. Operational mechanics and tracing on sample inputs.
2. Best, Average, and Worst-case workloads on CPU and Memory (RAM).
3. Direct comparative evaluation and industry use cases.
